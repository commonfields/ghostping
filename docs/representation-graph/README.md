# Representation Graph V1

One authoritative fact → bounded known representations → cheap deterministic
observation → drift detection → connection to existing AI evidence.

Laws: authority is not observation; observation is not interpretation;
citation is not causality; absence is not contradiction; failure is not
absence; UNKNOWN is not false; derived state is recomputed.

- Evidence Protocol V1 stays frozen; source objects are separate.
- Firecrawl/Playwright are future collector adapters, not dependencies.
- No recursive crawling, no MCP/public API, no LLM extraction, no scores.
